# 未成年人AI陪伴治理后台

把"只愿意向 AI 倾诉"的学生**及时接回到真实人际关怀**中，而不是再造一个聊天机器人。
本仓库是该治理后台的**领域内核 + 契约 + 虚构可核验样例**：系统只接收脱敏会话信号，
自动分级只决定"把哪位有资质的人、在多长时限内接进来"，所有判断都要说明依据、允许人工否决，
授权撤回、跨校转介、规则换版、夜间值守、到期删除都留下哈希链证据。

> 仓库内全部为虚构样例，不含真实个人信息、账号、密钥或连接凭据；系统内不存在任何对话原文。

## 边界：系统里有什么、没有什么

- **没有**任何聊天消息原文。受控客户端在本地完成抽取，入域的只有：化名、时间、模型版本、
  窗口标识、特征白名单数值（情绪分、孤立感、自伤暗示计数……）和至多 3 条 ≤24 字的短语片段。
  读取器 `redact_signal` 会丢弃未知特征与一切 `message/text/content` 字段。
- **有**分级判定与依据、关怀案件与接力时限、按角色最小化的摘要、只追加审计哈希链、
  到期删除证明。

## 分级与"把人接进来"

| 等级 | 触发（规则包 risk-rules-v1，节选） | 承接资质 | 真人接触时限 |
|---|---|---|---|
| normal | 普通波动 | 不开案件，只入去标识趋势（k=5 匿名桶） | — |
| watch | 近14日孤立感3次≥70；AI排他依赖叠加孤立；睡眠紊乱 | teacher | 下一工作日12:00前 |
| urgent | 近3日自伤暗示；情绪分3次≤30且绝望短语累计≥2 | counselor | 24小时 |
| emergency | 24小时自伤暗示累计≥2；出现伤害他人现实暗示 | psychologist | 30分钟 |

一次等级上升开启一个"接力段"。**只有面对面或语音的真人接触才能闭合接力段**——
AI 对话、文字留言会被拒绝。心理老师/专职心理教师可在看到依据后**人工否决**：
机器结论与依据保留不删，降级必须在当前等级已经完成真人接触之后，且降级后的较低等级
仍开启新接力段（降级不等于消失）。

- **夜间值守**：22:00–次日7:00 的 watch 信号排队到次日早晨复核，深夜不打扰；
  urgent/emergency 仍立即路由夜间值班人员；无合格值守时标记 `escalation-unassigned` 留痕。
- **家长联络**：仅 urgent/emergency 产生一条必要安全结论（不含特征值、片段、规则码），
  按"案件+接力段+等级"幂等；投递层重试只增加尝试计数，**绝不发出第二条**。

## 三类人分别看到什么

显式矩阵在 `src/governance/visibility.py`，学生可查看的"谁可见什么"说明由
`student_access_report()` 生成（样例见 `fixtures/replay/student-visibility.json`）：

- **学生**：自己的脱敏信号、等级、每条判定依据、审计记录与删除证明；知道谁能看到什么。
- **家长**：只有必要安全结论（`guardian_digest`）与等级；看不到特征值、片段和依据。
- **班主任**：等级与去标识趋势，用于日常关心，默认只见化名（不能解封真实身份）。
- **心理老师 / 专职心理教师**：承接案件后可见脱敏信号、依据、接力记录；解封真实身份
  需单独授权且留痕。
- **审查人员**：判定依据、每段接力是否在 SLA 内完成真人接触、审计链、删除证明。

任何角色都看不到 `raw_message`——系统本身不持有它。

## 可核验事件（只追加哈希链）

授权授予/撤回、入域拒绝（未登记化名/授权缺失/模型停用/学校未登记）、每次自动判定
（等级、命中规则、规则版本、模型版本）、立案与升级、派单与解封、家长通知与去重键、
真人接触（时间/人员/资质/渠道）、人工否决、规则包发布、模型登记/停用、
跨校转介三阶段、数据物理删除证明——全部进入 SHA-256 哈希链。
改动任何一条历史证据，`AuditLog.verify()` 即失败。

跨校转介只移交**安全结论**（不含特征与片段），接收校必须重新确认监护授权；
信号保留 90 天、趋势 365 天、案件与转介 3 年、审计 5 年，到期物理擦除并出具
含"擦除前状态哈希"的删除证明。

## 目录

```
contracts/
  context.schema.json          领域资料契约
  redacted-signal.schema.json  脱敏信号契约（禁止 message/text/content）
  governance-event.schema.json 审计事件契约（动作枚举 + 哈希格式）
src/
  context.py                   领域资料读取器
  governance/
    signals.py      脱敏清洗 / 信号历史 / k-匿名趋势
    rules.py        版本化规则包、条件、分级与命中依据
    triage.py       判定结论（含人工否决）与中文依据
    cases.py        关怀案件、接力段、资质路由、SLA、幂等发件箱、最小化摘要
    schedule.py     服务时段、夜间判定、工作日时限、值守名册
    consent.py      监护授权登记与撤回历史
    identity.py     化名注册与最小必要解封
    models.py       陪伴模型/抽取器版本登记
    schools.py      学校与服务窗口登记
    referral.py     跨校转介
    retention.py    到期删除与删除证明
    visibility.py   角色可见性矩阵
    audit.py        只追加哈希链
    engine.py       用例编排（唯一状态变更入口）
fixtures/
  context.json        领域资料（v2）
  setup.json          虚构学校/模型/值守/学生/授权样例
  replay/             端到端回放产物（审计链、接力审查、家长视图、趋势、删除证明…）
scripts/replay.py     确定性回放：固定虚构事件，重跑逐字节一致
tests/                48 个单元/契约测试
```

## 本地校验

```bash
python -m unittest discover -s tests   # 48 个测试
python -m scripts.replay               # 重放虚构全流程，重生成 fixtures/replay/
```

回放结束时会自动校验哈希链；再跑一次并对比 `fixtures/replay/` 可验证可复现性。
